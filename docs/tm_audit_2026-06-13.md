## Track A — deployment correctness fixes [deploy], one branch each, local validation

A1. **Ponderhit deadline trio race** (uci.rs:809-811 -> search.rs:966,
    2065-2082, uci.rs:554-555). Three Relaxed atomics read
    non-atomically; ARM reorders can (i) zero the soft floor
    (instant-emit class) or (ii) make the post-completion wait loop see
    soft=0 and spend the full 46% hard window when ponder finished
    early — overspend on exactly deployment's best moves. Fix: pack
    into one AtomicU64 pair or Release-store/Acquire-load with hard as
    the publish flag. Violates the repo ARM standard as-is.
A2. **GUI stop erased in ponderhit window** (uci.rs:539-567) +
    **uninterruptible stockpile-floor sleep** (search.rs:2602-2613 —
    comment claims it polls stop; it cannot, :2603 sets stop itself;
    ponderhit fresh-search floor = entire remaining clock). Fix: thread
    a distinct external-stop Arc<AtomicBool> into SearchInfo; poll it
    in the sleep loop and the fresh-search path.
A3. **Zero/negative clock fails open** (uci.rs:1047-1077 +
    search.rs:2019-2023): `wtime -23`/`wtime 0`/`movetime 0` ->
    unbounded search -> forfeit at flag-edge. Parse i64, clamp >= 1ms
    budget when clock tokens present.
A4. Small bundle: tm_max_time missing from the C6 per-go reset (latent,
    one line); `go infinite` emits at depth-64 exhaustion instead of
    waiting for stop; movestogo branch omits the increment term
    (CCRL-relevant); instant-emit fallback should probe TT before
    root_legal[0]; consider 1024-node time gate when MoveOverhead<50 or
    after TB disk probes.

## Track B — fleet-visible improvements [sprt]

B1. **Stability shape: linear -> table.** 10/10 engines scale on
    stability; the strongest use nonlinear front-loaded shapes
    (SF logistic w/ cross-move carry, Stormphrax power law,
    Viri/Alexandria/Clarity tables). Consensus: ~2.4x at stability 0,
    ~1.1 by 2, floor ~0.75. Port: 5-entry tunable table
    {238,129,107,91,71}/100 (Alexandria ≈ Stash ≈ Viri), cap 4.
    Focused SPSA ~1000 iters then LTC SPRT.
B2. **One-sided falling-eval with cross-move anchor.** 6/10 anchor on
    the previous MOVE's search score; Berserk/Integral add scores[d-3]
    and make both terms max(0,·) — extend on falling eval, never
    shrink on rising (SF's 0.581 clamp floor = same asymmetry). Coda
    uses prev-iteration only, two-sided. Port Berserk shape; needs
    persisting root score across `go` (Obsidian searchPrevScore).
B3. **Within-iteration bestMoveChanges factor — NEARLY FREE.** Only
    SF+Reckless have it (i.e. #1 and #2), orthogonal to
    across-iteration stability. Coda ALREADY MAINTAINS the counter
    (tm_best_move_changes, currently TMDebug-only; field doc stale).
    Wire as factor: SF 1.088 + 2.315*changes with x0.5/iter decay, or
    Reckless ln1p shape.
B4. **SF don't-deepen rule**: at iteration end, if elapsed > 50% of
    scaled budget, don't start an iteration that won't finish (SF
    re-searches at reduced depth; the simple stop variant is the
    composable port).
B5. Hygiene (no SPRT): delete dead TM_ASP_THRESHOLD/TM_ASP_MULT_10X
    tunables (full-sweep SNR burn — never read since Phase 13); fix
    stale field docs (tm_asp_fail_low, tm_best_move_changes); rename
    _fullmove (load-bearing despite underscore); drop the
    scale/_=scale dead pair and the Phase-13 tombstone fn; REWRITE
    CLAUDE.md's TM section (describes the pre-Phase-13 model — wrong
    spec: actual is Viridithas windows, 24/40 mtg, 94% inc, 46%/60%,
    phase-mult, no emergency mode). Consider exposing clock-mode magic
    constants (stability table, 0.34 fail-low, forced mults/margins,
    trend slope, phase consts) as tunables for the next LTC production
    tune. Also: mate early-emit is sign-agnostic (stops deepening when
