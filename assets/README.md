# Coda brand assets

Each logo comes in a **dark** variant (for dark backgrounds) and a **light**
variant (for light backgrounds). Pick by background, not by preference — the
wordmark is near-black in the light set and off-white in the dark set.

| File | Size | Use |
|---|---|---|
| `coda-logo-wide.png` / `coda-logo-wide-light.png` | 1600×460 | **Horizontal lockup** — README banners, rating lists (CCRL), site headers |
| `coda-logo.png` / `coda-logo-light.png` | 1254×1254 | **Square lockup** — social cards, splash images |
| `coda-mark.png` / `coda-mark-light.png` | 236×262 | **Mark only** (pawn + ring, no wordmark) — avatars, favicons |
| `coda-mark-256.png` / `coda-mark-light-256.png` | 256×256 | Mark, pre-scaled square |

The mark stays legible down to about 32 px; below that prefer a solid-colour
silhouette.

## Colours

| Role | Dark variant | Light variant |
|---|---|---|
| Background | `#0B0B0B` | `#FAF9F6` |
| Pawn + wordmark | `#F5F1E8` | `#18181A` |
| Ring | `#9A9281` | `#7A6C56` |
| Tagline | `#CDC5B4` | `#817969` |

## Usage

Please don't recolour the mark, restretch the lockup, or set the tagline in a
different typeface. Scaling and cropping to the mark are fine.
